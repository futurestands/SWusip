# SWUSIP — South Western Umbrella Call Centre

Institutional Android softphone and offline customer directory for the South Western
Umbrella of Water and Sanitation, Ministry of Water and Environment, Uganda.

Open the [Android project](baresip-studio-master/) in Android Studio.

The genuine Baresip native SIP engine is retained. SWUSIP 1.0.2-pilot is installed
on the authorised Android 15 handset and eight Android instrumentation tests pass,
including keypad editing and unprovisioned Call feedback. Directory workflow
review requires workspace authentication. Live PBX/audio
verification remains outstanding. No production PBX or server settings have changed.
