# SWUSIP — South Western Umbrella Call Centre

Institutional Android softphone and offline customer directory for the South Western
Umbrella of Water and Sanitation, Ministry of Water and Environment, Uganda.

Open the [Android project](baresip-studio-master/) in Android Studio.

- [Project overview and build instructions](baresip-studio-master/README.md)
- [Pilot setup and phone authorisation](baresip-studio-master/docs/SWUSIP_PILOT_GUIDE.md)
- [Feature inventory and data model](baresip-studio-master/docs/SWUSIP_REDESIGN.md)
- [Excel customer template](baresip-studio-master/docs/templates/swusip-customers.xlsx)
- [Verification evidence](baresip-studio-master/docs/evidence/swusip-pilot/verification.json)

The genuine Baresip native SIP engine is retained. Device installation, authenticated
directory review and live PBX/audio verification are deferred until the authorised
phone is available. No production PBX or server settings have been changed.

Original third-party copyrights and licence conditions remain in the project and
the application's Third-Party Licences section.
